# Note draft saving, naming, and discard

Type: grilling
Status: resolved
Claimed by: Codex
Blocked by: Note draft persistence and library behavior

## Question

How should Note drafts save and age? Decide the autosave guarantee, default title and timestamp, reopen behavior after app restart, and the explicit action required to discard or delete a draft without accidentally losing notes.

## Resolution

Note drafts autosave continuously while edited and survive app restarts. New drafts receive a default local date/time title. They never expire or disappear automatically; deletion is always an explicit user action.
