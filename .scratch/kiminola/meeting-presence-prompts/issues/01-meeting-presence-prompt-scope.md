# Meeting presence prompts are post-MVP and never auto-start

Type: grilling
Status: resolved
Blocked by: None

## Question

Should Kiminola add local meeting-app detection as an MVP behavior, and should detection automatically start recording?

## Resolution

This is a post-MVP feature. Kiminola may detect that the user is likely in a meeting and show a screen notification, but it must never start audio capture automatically. The notification may offer to open a Notepad or let the user explicitly start a Meeting.
