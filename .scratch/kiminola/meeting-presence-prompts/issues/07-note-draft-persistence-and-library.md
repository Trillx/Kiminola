# Note draft persistence and library behavior

Type: grilling
Status: resolved
Claimed by: Codex
Blocked by: Notepad-to-Meeting lifecycle

## Question

How should a standalone Note draft be saved and surfaced? Decide its title and timestamp defaults, whether it appears in the meeting library or a separate notes view, autosave/reopen behavior, explicit discard/deletion, and how the user finds a Note draft later if it never becomes a Meeting.

## Resolution

Standalone Note drafts appear in the same library as Meetings, with a distinct **Note draft** type so users can find and reopen them without confusing them with recorded Meetings.

Autosave, naming, reopening, and discard behavior remain open decisions.
